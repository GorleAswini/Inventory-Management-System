# Academic Deliverables: System Architecture Document

## Architecture Overview
- **Pattern:** ASP.NET Core MVC with Service Layer (3-Tier Layered Architecture).
- **Presentation Layer:** ASP.NET Core MVC Controllers, Razor Views, Bootstrap 5 UI.
- **Business Logic Layer:** Service classes implementing business rules, validation, notification triggers, and audit trail orchestration.
- **Data Access Layer:** Entity Framework Core interacting with SQLite database.
- **Security Architecture:** Cookie Authentication, Claims-based Role authorization, and Permission checking filters.
