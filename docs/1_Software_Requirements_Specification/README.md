# Academic Deliverables: Software Requirements Specification (SRS)

## Included Documents
1. **Business Requirements Document (BRD)**:
   - High-level business goals and return on investment (ROI).
   - Traceability matrix linking business rules to test cases.
2. **Functional Requirements**:
   - Authentication (FR-AUTH-001 to FR-AUTH-005)
   - Asset/Inventory Management (FR-ASSET-001 to FR-ASSET-007)
   - Role & Permissions Management
   - Organisation Profile
   - Notifications (FR-NOTIF-001 to FR-NOTIF-003)
   - Reports & Analytics
3. **Non-Functional Requirements (NFR)**:
   - Performance (NFR-001)
   - Usability (NFR-002)
   - Responsive Design (NFR-003)
   - Security & Password Hashing (NFR-004)
   - SOLID & Maintainability (NFR-005)
   - Reliability & Error Handling (NFR-006)
   - Client & Server-side Validation (NFR-007)
